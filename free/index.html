What's in every pack

Horizontal sprite strips with JSON (frame size, fps, loop, anchor), GIF previews, the palette as .gpl/.hex/.pal/.png, and a SKILL.md + catalog.json so a coding agent can place the sprites for you. The full packs add Godot 4 scenes.
